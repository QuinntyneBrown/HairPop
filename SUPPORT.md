# Support

HairPop is under development. Community support is provided on a best-effort basis.

| Need | Where to go |
| --- | --- |
| Question about the project or its documentation | Search [existing issues](https://github.com/QuinntyneBrown/HairPop/issues), then open an issue |
| Reproducible bug | Open an issue with steps to reproduce, expected behavior, and actual behavior |
| Feature or behavior proposal | Open an issue describing the customer need and proposed outcome |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not post exploit details publicly |
| Conduct concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

The [README](README.md), [mock guide](docs/mocks/README.md), and [contributing guide](CONTRIBUTING.md) may answer common setup and project questions. There is no guaranteed response time or commercial support channel.

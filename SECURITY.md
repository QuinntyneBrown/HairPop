# Security policy

HairPop is under development and has no versioned release. Security fixes currently target the active development branch.

## Report a vulnerability

Please report security concerns privately. Do not open a public issue or pull request containing exploit details or personal data.

Use [GitHub private vulnerability reporting](https://github.com/QuinntyneBrown/HairPop/security/advisories/new) if it is available for this repository. If it is unavailable, contact the [project maintainer](https://github.com/QuinntyneBrown) privately through the contact method listed on their profile.

Include the affected page, endpoint, file, or design; steps to reproduce; the likely impact; and the relevant branch or commit when known. Share only the data needed to demonstrate the problem, and give the maintainer time to investigate before public disclosure.

## Scope

Reports about code, configuration, or designs in this repository are welcome. The customer journey mocks use illustrative information and are not a live service.

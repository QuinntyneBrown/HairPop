Accounts and signing in

Creating an account, signing in, and what HairPop deliberately does not reveal.

Where these screens live

Create account

/sign-up

POST /api/auth/register

Sign in

/sign-in

POST /api/auth/sign-in

Session

The top bar account link

GET /api/session

Join HairPop

  • Name, email, password of 12+ characters
  • Error summary links to fields
  • Nothing sent until valid

Failure, then success

  • Nothing you entered was lost
  • Retry reuses the request key
  • Same answer for known emails
  • Verification link sent

Sign in problems

  • Validates before sending
  • Never says which credential was wrong
  • Password cleared, email kept
  • Rate limit says when to retry

Signed in

  • Forgot your password and Create an account
  • Top bar shows “Maya”
  • Links to account settings

Two details worth knowing

Safe return address

/sign-in?returnUrl=/help returns to Help.

An address that leaves the site is ignored.

Existing sessions

A valid session shows the customer’s first name on any page.

Things to remember

  • Name, email and a 12-character password, validated before sending
  • Failures keep every entry; retries make only one account
  • Sign in never reveals which credential was wrong
  • Rate limits say when to try again
  • The top bar shows the customer’s first name once signed in

Nia Okafor

Knotless braids and twists · Toronto West

Placement: directly above the page header inside .product-main, aligned to the content edge. Links are 24 px tall targets, 8 px apart. AC-4

Sizes

One size: --text-body-sm with 24 px link targets (--target-min) and --space-2 gaps. Width comes from the items; long paths wrap.

States

Forced with data-state; the real page uses :hover and :focus-visible. The pointer-down state keeps the hover look. The current page is not a link, so it has no hover or focus state. Below 768 px these cells collapse to the parent link, as the product does.

Responsive

Component CSS uses viewport media queries, so each frame is a real viewport. Below 768 px only the parent link shows, with a chevron; from 768 px the full path shows. The collapse rules are a specimen style (D-3) because components.css has none yet; the “current (drift)” frame shows today’s stylesheet.

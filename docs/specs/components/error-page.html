Error page

Sizes

One size: the empty state's full size inside the page's main region. Compact is for regions inside a page, never for an error page.

States

An error page is a static response: no loading, empty or nested error state. Its interactive states belong to the recovery action; a failed retry keeps focus on “Try again” and is announced through the empty state's role="alert" region.

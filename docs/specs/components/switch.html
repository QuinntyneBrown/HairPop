Switch

A setting that applies the moment it changes: a native checkbox with role="switch", inline or as a settings row. Requirements: switch.md. Design system: switch.

Variants

Inline (label after the switch) and settings row (.switch--end) with a description. AC-1, AC-3, AC-12, AC-13
Track 44 × 24 px, thumb 20 px inset 2 px; on slides the thumb 20 px and fills the track with the accent. AC-2, AC-4

Sizes

Switches have one size: a 44 × 24 px track in a row at least 24 px tall.

States

Pointer and focus states are forced with data-state; the rest use the real attributes (checked, disabled). The on-hover cell renders the resting on switch, because hovering an on switch changes nothing; the stylesheet’s documentation hook input[data-state="hover"] would paint the off-hover track on it.

Failed save

Reminders not updated.Try again.
After a failed save the page writes the saved value back (off) and shows its toast; the switch emits nothing for the revert (D-4). No invalid or busy state exists (D-3). AC-7, AC-8, AC-9

Keyboard focus

Keyboard focus: the ring follows the pill. Tab focuses, Space toggles, Enter does not. AC-10, AC-11

Both themes

AC-14, AC-16 (forced colours need the D-8 rules; Chromium dropped the on switch without them), AC-19 (reduced motion: instant)

Responsive

Every frame is a real viewport. At 200 % text the design system’s row-reverse settings row pushes the label past the card’s start edge; the required rule (D-6, specimen-only style) wraps the switch beneath the label instead and is identical at 100 % text.

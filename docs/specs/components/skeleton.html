Skeleton

Blocks that hold the loaded layout while content loads: one status message per region, patterns for story cards, appointment rows and list rows, and a slow-read line after 10 seconds. Requirements: skeleton.md. Design system: skeleton.

Sizes

Blocks have no sizes of their own: each takes the size of the content it stands for (em-based text, 3:2 media, control heights).

States

Skeletons are not interactive. Loading shimmers; reduced motion holds the blocks still; loaded content replaces them in one update.

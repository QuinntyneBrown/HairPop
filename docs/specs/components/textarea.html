The three customer textareas, all auto-grow (.textarea--auto-grow, D-10): “Your review”, “Hair details”, and “Reason” in the report dialog. AC-1, AC-2, AC-15

Auto-grow

Auto-grow: 100 px minimum, grows with the text, capped at 6 × --control-height-md (240 px, about eight lines), then scrolls. No resize handle. AC-3, AC-4

Default

Default variant: vertical resize handle; kept for wide-screen tools. AC-4

Sizes

One size (16 px text). The minimum is 100 px; rows sets the default variant's start height above it.

States

Pointer and focus forced with data-state; the rest use real attributes.

Keyboard and focus

Focused: accent border and flush 2 px ring. Enter inserts a new line; Tab leaves the field. Border changes are instant under reduced motion. AC-5, AC-13, AC-14, AC-21
Read-only (focusable, sunken, dashed) and disabled (skipped by Tab, text kept). AC-10, AC-11

Both themes

AC-16, AC-17, AC-18

Responsive

Always the column's full width; never in a .form-row. The minimum and cap are rem-based, so they scale with text size.

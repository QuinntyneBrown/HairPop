Responsive

The table is always its container’s width; extra columns scroll inside the wrapper, never the page. While it overflows, the wrapper is a named, focusable region (D-4); at 1280 px it fits and has no tabindex. At 200 % text size the table scrolls inside the wrapper as on a phone.

Sizes

One size per variant. Inline, external and inherit links take the size of the text they sit in; standalone links use --text-label at --font-size-md with a 24 px minimum height (--target-min).

States

Pointer and focus states are forced with data-state; the real page uses :hover, :focus-visible and :active. Visited links are not restyled, so the last column repeats the default. Links have no disabled, busy or error state.

Responsive

The link has no breakpoint rules of its own; every frame is a real viewport. The 200 % frames show the standalone label wrapping inside the card with the arrow at the end of the row, at full size (D-12). The last frame shows D-11: the external icon on the text line, after the last word.

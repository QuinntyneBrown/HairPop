Variants

$
Text, email, tel and number, each with the matching autocomplete or inputmode, as the consumer wrote them. Bound to Maya's details. AC-1, AC-2, AC-4, AC-15

Password

Hidden, then revealed: revealed renders type="text"; value, caret and focus stay; the “Show” button reports aria-pressed. Paste is never blocked; Enter submits the form. AC-12, AC-13, AC-14

Search box

Find braiders
Search box (div.search.search-box): icon hidden, one aria-label, Enter submits the inline form, Esc clears. AC-16, AC-17, AC-18
Search by style name.

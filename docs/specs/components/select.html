Select

The native select for one value from a known list: distances, Nia's offered times, her services. Requirements: select.md. Design system: select. Specimens apply the CRD's required styles (marked “Specimen only, not product CSS” in this page's style block); frames labelled “current (drift)” show today's stylesheet.

Variants

Native select in the filter dialog; placeholder option and day groups in the change dialog (each option names the whole value, D-6); the booking “Service”, preselected from Nia's profile. AC-1, AC-3, AC-5, AC-8, AC-12

Sizes

fieldSize sm, md, lg: 32, 40 and 48 px (D-4). AC-2

States

Pointer and focus forced with data-state; the rest use real attributes. A native select has no read-only state (D-5).

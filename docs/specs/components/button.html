Toggle

Toggle off and on: aria-pressed uses the selected look shared with chips and the current nav link. Activation flips it. AC-18

Expanded (menu trigger)

Menu trigger closed, then open. Open triggers hold the variant's active fill (required, D-13; drawn by a specimen-only rule, since components.css has no .btn[aria-expanded="true"] rule yet). AC-31

Busy

Busy keeps the label (painted transparent, so the name is unchanged), the size and the focus. Mocks that show a disabled “Working…” button are drift (D-7). The spinner keeps turning under reduced motion. AC-14, AC-15, AC-16, AC-23, AC-30

Disabled

Native disabled: 50 % opaque, out of the Tab order, emits nothing. Only <button> hosts; never on an <a> (D-3). AC-17

Keyboard focus

See braiders for this style
Focus ring: 2 px --color-focus-ring, 2 px offset, forced here with data-state="focus". Real pages show it on :focus-visible only; Enter and Space activate the button, Enter alone follows the link. AC-19, AC-20, AC-21

Responsive

Component CSS uses viewport media queries, so every frame is a real viewport. The 200 % text frames show D-5: the required wrapping uses a specimen-only style, and the “current (drift)” frame shows today's stylesheet overflowing. Button size and padding do not change across breakpoints; the containers (.form-actions, .dialog__footer, .page-header__actions) change width and order.

AC-27, AC-28 (200 % browser zoom reflows to the narrow frames)

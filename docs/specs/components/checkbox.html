Checkbox

Independent options saved with their form: single, described, card, grouped and hidden-label checkboxes on a native label and input. Requirements: checkbox.md. Design system: checkbox.

Variants

Single (no description), with description (cookie preferences, D-4), and card. The name is the label only; the description is the accessible description (D-3). AC-1, AC-2, AC-4, AC-5

Group

Styles to include
Group inside the form field's fieldset and legend. The group host carries .choice-group; value ['knotless', 'passion-twists']. AC-13, AC-16

Sizes

Checkboxes have one size: a 20 px box (--choice-size) in a row at least 24 px tall; the width is the container’s and the label wraps under itself.

A long label wraps under itself; the box stays on the first line. The row is the click target. AC-3, AC-6

States

Pointer, focus and indeterminate states are forced with data-state; the rest use the real attributes (checked, disabled, aria-invalid).

Invalid group: every child carries aria-invalid; the error is linked once from the fieldset (D-13). The error copy is the form's. AC-14

Cookie preferences after Maya unchecked the box: while “Save preferences” is busy and after the save fails, the checkbox stays enabled and keeps her value (D-7). AC-10, AC-11, AC-12

Keyboard focus

Keyboard focus in a dialog: 2 px ring, 2 px offset, around the box only (forced with data-state). AC-17

Both themes

AC-20, AC-21 (forced colours: checked box Highlight, edges CanvasText), AC-24 (reduced motion: instant)

Responsive

Every frame is a real viewport. The checkbox itself has no breakpoint rules; a horizontal group stacks below 768 px (D-9), and a word longer than the label column breaks (D-15), both shown with specimen-only styles beside today’s stylesheet. The cookie frames show the phone dialog, which spans the viewport.

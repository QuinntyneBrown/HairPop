Responsive

Only .avatar--xl changes with the viewport (48 → 64 px at 768 px). The avatar never shrinks; the profile head moves the name under it on phones. The 200 % frames show D-5 with a specimen-only style; the “current (drift)” frame shows today’s group overrunning its card.

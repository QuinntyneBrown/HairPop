AC-23, AC-24

In the dark theme the surface is grey 900 on a grey 950 canvas, so cards read as raised by lightness as well as their shadow.

Responsive

Component CSS uses viewport media queries, so every frame is a real viewport. Text at 200 % is shown as what it is to the rem media queries: a 180 px layout drawn at twice the size. The card has no breakpoints of its own; the grid and the row layout change. The 320 px frame shows D-3: the header wraps the badge under the title instead of letting it cross the card edge. With the browser’s text size at 200 % the media queries (in rem) give the one-column layout at 1280 px, as in the 360 px frames.

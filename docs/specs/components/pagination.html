Sizes

One size: 32 px items (--control-height-sm) with --space-2 inline padding and 4 px gaps; --text-label with tabular figures.

States

Forced with data-state; the real page uses :hover and :focus-visible. Active keeps the hover look. The current page carries aria-current="page"; an unavailable end is role="link" aria-disabled="true" without href, 50 % opaque, skipped by Tab.

Forced colours

In forced colours every item gets the same LinkText border and the current page’s fill is removed; the component adds a 2 px Highlight outline to the current page (D-9). Emulate forced colours in the browser’s rendering tools to see it on this page. AC-19

Responsive

Every frame is a real viewport. Below 768 px the narrow window (first, current, last) shows; from 768 px the wide window (current ± 2). Below 640 px the summary takes its own line. The window rules, ellipsis box and simple modifier are specimen styles (D-3 to D-6) because components.css lacks them; without them every window item would show and wrap.

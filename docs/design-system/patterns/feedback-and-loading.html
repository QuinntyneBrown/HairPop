Pattern

Feedback and loading

Every action Maya takes gets an answer in the right place and at the right volume: inline beside what changed, a toast for news, a banner for a condition, a dialog only when she must decide.

Overview

Feedback is chosen by two questions: where did the change happen, and does Maya need to act? Loading is chosen by whether we know the shape of what is coming. The mocks cover every case: field errors, partial-load warnings, offline banners, booking-update toasts, busy dialogs, and skeleton screens for every page.

Undo instead of confirm

When an action is reversible (removing a saved braider, clearing filters), do it at once and offer Undo in the toast. Only offer Undo when it really reverses the action; a review that has been posted, or a time Nia confirmed, has nothing to undo.

Responsive

  • Toasts dock bottom right at 24rem from 640px and span the bottom edge on phones, above the safe area.
  • Banners span the full width of main and wrap their text; they never become toasts on phones.
  • Skeleton grids use the same .feature-grid columns as the loaded content, so nothing jumps at any width.

Accessibility

  • One polite role="status" region per page holds toasts; errors that need attention use role="alert" in a separate region, never nested inside the status region.
  • Status is colour + icon + text: every alert, banner and toast has an icon and a bold lead.
  • Skeleton regions keep their own name ("Styles"), set aria-busy="true", and hold one visually hidden role="status" message that names what is loading ("Loading styles"); the shapes themselves are aria-hidden and carry no content.
  • Toasts stay at least 8 seconds, pause on hover and focus, and danger toasts never auto-dismiss (2.2.1).
  • Under reduced motion, shimmer and pulse pause; spinners keep turning because they are the only sign of progress.

Content

  • Lead with the outcome in a few words, then one sentence of detail: "Time needs a change. Nia suggested Sun 25 Oct at 11:00 am."
  • Failures say what is safe: "Your request is still saved. Retry when connected."
  • Loading text names the thing: "Refreshing braiders near Toronto…", not "Loading…".
  • Actions in feedback are verbs that do the next step: "View appointment", "Retry reviews", "Undo".

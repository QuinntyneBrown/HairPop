How to use

  1. Link the fonts, the tokens and the component CSS, in that order:
    <link rel="stylesheet" href="assets/fonts/fonts.css">
<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">
  2. Use the class names and attributes from each component's Code section. They are the mocks' BEM classes, so end-to-end locators written against the mocks keep working.
  3. Read tokens by role (var(--color-fg-muted), var(--space-4)), never by value. To re-skin one component, override its component tokens (--btn-bg, --card-padding); to change a theme, override semantic tokens only.
  4. Generate platform constants from tokens/tokens.json (DTCG format; dark values under $extensions).
  5. Press t or use the toggle in the sidebar to switch every page between light and dark.

Foundation

Accessibility

Choosing a braider should be as easy with a screen reader, a keyboard or 400% zoom as with a thumb. HairPop meets WCAG 2.2 AA by construction, in both themes.

Overview

Accessibility is built into the tokens and components, not added per screen. Contrast is a property of token pairs, focus is one shared ring, targets come from size tokens, motion respects the person's preference through the motion tokens, and every component page states its role, keyboard model, labelling, contrast, motion and touch behaviour.

  • Every text and control pairing passes in light and dark (148 pairs, checked by script).
  • One visible focus ring on every interactive element.
  • Every target at least 24×24px; primary mobile actions 44px.
  • Native elements first; ARIA only following the WAI-ARIA Authoring Practices patterns named on each component page.
  • Status is never colour alone: colour plus icon plus words.

Component contract

Every component page's Accessibility section answers the same seven questions:

  1. Role and pattern: the element or ARIA pattern, linked to the WAI-ARIA Authoring Practices Guide.
  2. Keyboard: a key table (Tab, Shift+Tab, Enter, Space, Escape, arrows, Home and End).
  3. Focus: where it starts, where it goes on close, how the ring looks.
  4. Labelling: what must be named, how, and what is announced.
  5. Contrast: the token pairs with live ratios in both themes.
  6. Motion: what animates and what reduced motion does.
  7. Touch: target sizes and the alternative to hover.

Usage

Testing procedure

  1. Contrast: python .claude/skills/extracting-design-systems/scripts/check_contrast.py docs/design-system/tokens/tokens.css must report 0 failures for light and dark.
  2. Structure: check_design_system.py docs/design-system checks labels, names, alt text, landmarks, headings and links.
  3. Keyboard: Tab through each changed screen; every control is reachable, the order matches the layout, the ring is always visible, dialogs trap and return focus, Escape closes.
  4. Screen reader: NVDA with Chrome or VoiceOver with Safari on one form (booking request), one dialog (cancel appointment) and one list (my appointments).
  5. Zoom: 200% text size and 400% page zoom at 1280px; nothing clips or scrolls sideways.
  6. Preferences: emulate prefers-reduced-motion, prefers-contrast: more and forced-colors: active in Chromium DevTools.

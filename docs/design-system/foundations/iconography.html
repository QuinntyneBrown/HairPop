Foundation

Iconography

HairPop icons are simple line drawings on a 24-unit grid. They support a label; they rarely replace one.

  • Overview
  • Grid and style
  • Sizes
  • Icon sheet
  • Glyph-to-icon mapping
  • Usage
  • Accessibility

Overview

Every icon is an inline SVG drawn on a 24×24 grid with a 2px stroke, round caps and round joins, no fill, and stroke: currentColor, so it takes the colour of the text beside it in both themes. Icons are defined once (the ICONS table in build.py, and the matching icon component in the product) and rendered with the .icon class.

The mocks drew icons with text glyphs (✦, ×, ⌕, ✓, →, ★, ⚠). Glyphs render differently per font and platform, can be read aloud by screen readers, and do not follow the stroke style. The system replaces each with an SVG icon; see the mapping.

Grid and style

The calendar icon at 96px, 24px and 20px. Strokes stay 2 units wide on the 24-unit grid at every size.

<svg class="icon icon--lg" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 6h16v14H4zM4 10h16M8 3v4M16 3v4"/></svg>
<svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 6h16v14H4zM4 10h16M8 3v4M16 3v4"/></svg>
  • Grid: viewBox="0 0 24 24"; live area 20×20 centred; optical size matched, not mathematical (a circle reaches the live-area edge, a square sits 1 unit inside).
  • Stroke: 2 units, stroke-linecap: round, stroke-linejoin: round, no fill. .icon--fill exists for the rare solid mark (a filled star in a rating) and is never used for UI controls.
  • Colour: currentColor only. Status icons get their colour from the component (--alert-icon, --toast-icon), never from the SVG.
  • Metaphors: one icon means one thing. The sparkle is the brand mark and the styles accent; it never means "new" or "AI".

  • Inside a button the icon is 1.25em, so it scales with the button size.
  • Leave --space-1 to --space-2 between an icon and its label; buttons and badges set this gap for you.
  • Do not scale icons with transform; change the size class so the stroke stays crisp.

Usage

  • Pair icons with text. An icon alone is only for universally understood controls (close, menu, more, search) and always has an accessible name.
  • Status always combines colour, icon and words: a warning badge says "Awaiting reply"; the icon only reinforces it.
  • Do not mix glyphs, emoji or icon fonts with the SVG set.
  • Do not rotate or flip an icon to make a new meaning, except chevrons for direction.

Accessibility

  • Decorative icons (next to a visible label) carry aria-hidden="true" and no <title>.
  • Icon-only controls name the control, not the icon: aria-label="Close dialog", not "X icon". Add a tooltip with the same words.
  • Informative standalone icons (a star in "4.9 ★") get visually hidden text: "4.9 out of 5 stars".
  • Contrast: icons that carry meaning reach 3:1 against their background (WCAG 1.4.11); the status icon tokens are checked in contrast-pairs.json.
  • Forced colours: currentColor follows the system text colour, so icons stay visible in Windows High Contrast.

Foundation

Typography

One family, Manrope, in a light display voice for headlines and a clear semibold for labels. Body stays at 16px, nothing drops below 12px, and long text stops at 65 characters.

Overview

HairPop type follows the Banaro typography tokens the mocks adopted: Manrope for everything people read, JetBrains Mono for codes and reference numbers. Headlines use the light weight (300) at large sizes with tight tracking, which gives the product its calm, editorial feel; labels and buttons use semibold (600) at 14px so they read as controls.

Components never set a size, weight and line height separately. They use a role shorthand: font: var(--text-label). Roles are the twelve decisions below; the scale, weights and line heights are the primitives they are built from.

Weights, line height and tracking

Five weights. Light (300) is reserved for display, h1 and h2, a deliberate brand choice carried from the mocks; regular is body; medium is h3 and captions; semibold is labels, h4 and overlines; bold is for rare emphasis inside running text.

Light 300Regular 400Medium 500Semibold 600Bold 700
  • Line height: tight 1.08 for display, h1 and h2; snug 1.3 for h3, h4 and labels in controls; normal 1.65 for body; relaxed 1.85 for lead paragraphs. The mocks gave h2 a raw 1.15; it now uses tight.
  • Letter spacing: tight −0.03em on light headlines; normal everywhere else; wide 0.14em only on uppercase overlines, eyebrows and badges.

Measure

Paragraphs stop at --layout-measure (65ch): the base stylesheet sets p { max-width: var(--layout-measure) } with text-wrap: pretty, and headings use text-wrap: balance. Empty-state text is narrower (36ch) because it is centred.

HairPop helps customers discover independent braiders and send appointment requests. A request is pending until the braider accepts it. Prices shown before confirmation are estimates; the braider confirms appointment details and policies directly with you.

The legal pages and long help answers read best at this width.

Usage

  • One <h1> per page, using the page title. Headings follow document order; pick the role by level, not by the size you want.
  • Section titles inside a card use the h3 role even when the element is an <h2>; the 36px h2 is for page sections on the canvas. The mocks rendered card titles such as "Medium knotless braids" at the full 36px h2; components.css now applies h3 inside cards.
  • Body copy is 16px everywhere, including phones; never shrink body text to fit.
  • Nothing is set below 12px (--font-size-xs). Uppercase is only for overlines, eyebrows and badges, always with wide tracking.
  • Prices, times, counts and ratings use font-variant-numeric: tabular-nums where they align in columns or change in place.
  • Reference numbers (HP-1048) may use the code role; everything else stays in Manrope.

Responsive type

  • Only display and h1 scale with the viewport, through clamp() with a rem floor, so user zoom still enlarges them.
  • Empty-state titles step from 22px to 28px at 768px; account links in the top bar from 14px to 16px.
  • Everything else is fixed. A breakpoint never changes body, label or caption size.

Accessibility

  • All sizes are in rem, so text resizes to 200% (1.4.4) and reflows at 320px (1.4.10).
  • Layouts survive text-spacing overrides (1.4.12): line height 1.5×, paragraph spacing 2×, letter spacing 0.12em, word spacing 0.16em. No text container has a fixed height.
  • Light 300 is used only at 36px and above, where it counts as large text and still exceeds 4.5:1 in both themes.
  • Glyphs in text ("✦", "★", "→") are wrapped in aria-hidden="true"; the words carry the meaning ("4.9 from 86 reviews").

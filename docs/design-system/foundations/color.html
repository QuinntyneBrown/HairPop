Foundation

Color

HairPop is plum on cool grey: one brand hue for action and selection, quiet neutrals for everything else, and four status colours that always travel with an icon and words.

  • Status colours

Overview

Colour is a two-step decision. Primitives (--palette-*) are the raw ramps and are never used by a component. Semantic tokens (--color-*) give a primitive a job, such as "page background" or "label on primary", and are the only colour tokens components and pages read. Themes swap the semantic layer; the ramps never change.

  • Plum is the brand and the only accent: primary buttons, the current nav item, selected chips, eyebrows, links and the focus ring.
  • Cool grey carries text, surfaces and edges. Most of every screen is grey.
  • Green, amber and red mean success, attention and danger. Info reuses plum. Status is never colour alone: it always has an icon or dot and a word ("Awaiting reply", "Confirmed").

The mocks named the brand ramp --palette-blue-* although every step is purple; the system renames it --palette-plum-* with identical values.

Primitive ramps

Steps run from 25/50 (lightest) to 950 (darkest). The grey ramp has five in-between steps (150, 350, 450, 750, 925) because the dark theme needs text and edge values between the standard steps; in the mocks these were raw hex values inside the dark theme.

Status colours

Each status has six roles: a tinted bg, readable fg text on that tint, a decorative border, an icon colour (3:1 on the tint), an icon-inverse colour for icons on the inverse toast surface, and a solid fill for badges. Danger adds --color-danger-solid-hover for destructive buttons.

On the inverse toast surface

Light theme flips to the 300 steps on the dark toast; dark theme flips to the 600/700 steps on the light toast.

Both themes

Dark is built from roles, not by inverting light. Surfaces get lighter as they rise (canvas grey 950, surface 900, raised 800), the accent lightens to plum 300 with plum 950 labels, status backgrounds become deep tints with light text, and shadows get darker and stronger.

Usage

  • Read colour by role: color: var(--color-fg-muted), never var(--palette-gray-600) and never a hex value. Components alias roles through their own tokens (--btn-bg, --badge-fg).
  • Plum means "act here" or "you are here". Do not use it for decoration beyond the brand mark, eyebrows and art panels (--color-accent-subtle).
  • Text goes on the background it was paired with in tokens/contrast-pairs.json. A new pairing is added there and checked before it ships.
  • Status colour always comes with an icon or dot and a word. A red border alone does not say "invalid"; the field error text does.
  • --color-border-default is decorative and may fall below 3:1. Anything a person must see to operate a control uses --color-border-strong.
  • Disabled text (--color-fg-disabled) is exempt from contrast and is never the only place information appears.

Adding a brand theme

A partner or seasonal theme is a new [data-theme] block that overrides semantic tokens only. Add its ramp as primitives, point the accent roles at it, add the theme to the contrast check, and run it.

:root { --palette-teal-300: …; --palette-teal-600: …; --palette-teal-700: …; }
[data-theme="studio"] {
  --color-accent: var(--palette-teal-600);
  --color-accent-hover: var(--palette-teal-700);
  --color-fg-accent: var(--palette-teal-700);
  --color-focus-ring: var(--palette-teal-600);
}
/* then: python check_contrast.py docs/design-system/tokens/tokens.css */

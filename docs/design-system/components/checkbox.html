Checkbox

Checkboxes turn independent options on or off before the person saves: remembering optional usage choices, confirming Nia's policy, picking several styles to filter by.

WCAG 2.2 AANative <input type="checkbox">Status: stable

Overview

Use a checkbox for an option that is independent of the others and takes effect when the form is saved: "Remember my optional usage choices" in cookie preferences, "I’ve read Nia’s cancellation policy" on a booking request. Use a switch when the setting applies immediately, and a radio group when exactly one option must be chosen.

Anatomy

  1. Box20px, 1px --color-border-strong, --radius-xs; fills with the accent when checked.
  2. LabelBody text; the whole label is clickable.
  3. Description (optional)Body-sm, muted; part of the label.

Variants

Styles to include
Single; group in a fieldset with a legend; card style for weightier choices.

Sizes

Checkboxes have one size: a 20px box in a row at least 24px tall.

Both themes

Responsive behaviour

  • Groups stack vertically below 768px; a short group of one-word options may run inline (.choice-group--inline) from 768px.
  • Labels wrap under themselves, never under the box (flex row, box aligned to the first line).

Theming

Unchecked: a --color-bg-surface box with a --color-border-strong edge. Checked and indeterminate: --color-accent fill with a --color-fg-on-accent mark. In dark the fill is plum 300 and the mark plum 950. Override --choice-size only for touch-heavy kiosks.

Accessibility

Role and pattern

Native checkbox inside its <label>; groups in <fieldset> with <legend>. See the APG Checkbox pattern for the tri-state parent.

Keyboard

KeyAction
TabMoves to each checkbox in turn.
SpaceToggles the focused checkbox.

Focus

The 2px ring with 2px offset surrounds the box only.

Labelling

The label states the option positively ("Email me when Nia replies"). Descriptions sit inside the label. Required checkboxes say why in their error.

Contrast

Box edge on card
Checked fill in dialog
Check mark on fill

Motion

Fill and border transition over --duration-fast.

Touch

The whole label row (at least 24px) toggles the box.

Content

  • Write labels as statements that are true when checked; avoid negatives ("Don’t email me").
  • Explain consequences in the description, not the label.
  • Legends name the group: "Styles to include".

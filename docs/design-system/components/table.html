Overview

Compare structured records with real column headers. The customer mocks do not yet show this core primitive. Its roles and states extend the same tokens and interaction rules as the extracted components.

Use it for this job; choose a different component when the interaction or information hierarchy changes.

Anatomy

  2. Visible contentNames the action, value, or status in plain language.
  3. Component classReads shared roles from the token stylesheet.

Accessibility

Role and keyboard

Tab reaches sortable headers, row links, checkboxes, and action buttons in reading order; sorting uses Enter or Space.

Focus and labelling

Keep the shared visible focus ring. The visible text supplies the accessible name; icon-only actions need an explicit label. Associate help and errors with the relevant control.

Contrast, motion, and touch

Text uses a 4.5:1 minimum, meaningful controls and focus boundaries use 3:1, and all actions keep a 24px minimum target with comfortable spacing. Reduced motion removes decorative transitions. Check the actual foreground and background pair in both themes on the Color foundation.

Content

Use sentence case. For table, keep the wording concrete and close to the value or action it describes. Show “Awaiting reply” until the braider accepts; label a price estimate as an estimate.

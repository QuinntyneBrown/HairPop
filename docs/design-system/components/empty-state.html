Empty state

An empty state fills a region that has nothing to show yet, nothing that matches, or nothing it could load, and gives the person one clear next step.

WCAG 2.2 AAStatus: stableIcon + title + one sentence + one action

Overview

Use an empty state when a list, gallery or panel has no items to render. It always has four parts: an icon in a tinted circle, a title that says what is (or is not) here, one sentence that explains why or what happens next, and one primary action that moves the person forward.

  • First-run: nothing exists yet ("No appointments yet"). Point to how things get here.
  • No results: search or filters excluded everything. Offer to widen or clear them.
  • Error: the content could not load. Say the person's work is safe and offer "Try again".
  • Permission: this account cannot open the content. Offer to sign in with the right account, and never say whether the content exists (another customer's appointment); use the forbidden copy of the error page.
  • Success: a form's job is done (request sent, review posted). The region becomes a confirmation with the next step.

Full-page errors inside the shell (404, 403, 500, offline) are documented as Error page.

Anatomy

  1. Icon64px circle (48px compact), tinted by variant; a 24px SVG icon, aria-hidden.
  2. Title--text-h3, 28px from 768px; a real heading at the right level for the region.
  3. TextOne sentence, --color-fg-muted, capped at 36ch.
  4. ActionsOne primary button; an optional secondary button or link.

Variants

The variant sets the icon tint and the copy formula; the layout never changes. (Examples here use <p class="empty__title"> to keep this page's outline; production uses a heading.)

Responsive behaviour

  • Centred at every width. The title grows from 22px to 28px at 768px; the text stays capped at 36ch so it never runs the full card width.
  • Actions wrap and centre. When the empty state fills the screen (every error page), add .empty--stack-actions: below 640px the actions stack in a column at the empty state's full content width, primary first; from 640px they sit side by side again.
  • Below 640px, use the compact size inside cards and dialogs so the action stays above the fold.

Theming

The icon circle reads --empty-icon-bg and --empty-icon-fg, which the variants map to the accent, danger or warning tokens. In the dark theme those become deep tints (plum 950, red 950, amber 950) with light icons, so the circle reads as part of the surface rather than a bright spot. There is no success tint: success states use the default accent circle with a check icon.

The circle sizes the icon inside it, whatever size class the icon carries: 24px in the full size and 20px in .empty--compact. In forced colours the circle's fill is removed, so it draws a CanvasText hairline outline and the icon follows the system text colour.

/* Re-skin the circle on a sunken well (an override, not a variant) */
.well .empty__icon { --empty-icon-bg: var(--color-bg-surface); }

Accessibility

Role and pattern

A plain <section> with a real heading at the right level for its region (h2 in a page's main area). No ARIA role is needed for first-run and no-results. When an empty or error state replaces content after a search or retry, announce it once: put the title text in a polite role="status" region ("No matches for these filters"), or use role="alert" only when an action the person took failed.

Keyboard

KeyAction
TabThe icon, title and text are not focusable; Tab reaches the primary action, then the secondary.
Enter / SpaceActivate the action (buttons) or follow it (links, Enter only).

Focus

Do not move focus to an empty state that appears on page load. After a failed retry or a filter change that empties the list, keep focus on the control the person used. On a success state that replaces a form, move focus to the empty-state title (tabindex="-1") so the confirmation is read.

Labelling

The icon is decorative (aria-hidden); the title carries the meaning. Never rely on the tint: "We couldn’t load…" says it is an error.

Motion

None. An empty state appears in place, without entrance animation, so it never delays the action.

Touch

Actions are medium buttons (40px) or larger; two actions keep 12px between them.

Content

  • Title names the specific thing: "No appointments yet", "No matches for these filters", "We couldn’t load the style gallery". Never a generic "Nothing here yet".
  • Text is one sentence: why it is empty or what happens next. Errors say what is safe: "Your details are safe."
  • Action is the next step as a verb phrase: "Explore styles", "Clear filters", "Try again", "Sign in".
  • Use the cast: "Nia’s first reviews will appear here…", not "This braider has no reviews."
  • Success is a request, not a booking, until the braider accepts: "Request sent to Nia", never "Appointment booked".

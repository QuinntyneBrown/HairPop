Theme toggle

The theme toggle switches the product between light and dark and remembers the choice, so a person who prefers dark at night is never flashed with white on the next page.

WCAG 2.2 AAToggle button (aria-pressed)Status: stable

Overview

Every product shell (customer and braider) carries one theme toggle in the top bar (L2-048). It is a button with the ghost variant and small size whose pressed state means "dark theme on". Without a saved choice the product follows prefers-color-scheme; once toggled, the choice is stored and applied before first paint.

Anatomy

  1. Button.btn.btn--ghost.btn--sm with aria-pressed.
  2. LabelConstant "Dark theme"; the pressed state, not the words, changes.

Variants

One variant: a pressed-state ghost button.

Sizes

Small only, to sit beside the account link.

States

Not pressed, pressed and focused. Pressed uses the button's pressed styling.

Responsive behaviour

  • Stays in the bar at every width, before the menu button on phones.

Theming

Sets data-theme="light|dark" on <html> and stores the choice in essential storage under hp-theme (a functional preference, not optional usage data). An inline script in the document head applies the stored value before styles paint.

Accessibility

Role and pattern

WAI-ARIA toggle button: native <button> with aria-pressed.

Keyboard

KeyAction
Enter / SpaceSwitches the theme and flips the pressed state.

Focus

Shared focus ring; focus stays on the button after switching.

Labelling

"Dark theme, toggle button, pressed" or "not pressed". The label never changes, so the state is not announced twice.

Contrast

Label

Motion

The theme switches instantly; no cross-fade.

Touch

44px target through the small button's padding.

Content

  • Label: "Dark theme". Not "Toggle theme" or a glyph.

Do and don't

Tokens

Uses the button's ghost and pressed tokens; it adds none of its own.

PartTokenLightDark
Label--color-fg-default
Pressed background--color-accent-subtle

Code

<button class="btn btn--ghost btn--sm theme-toggle" type="button" aria-pressed="false">Dark theme</button>

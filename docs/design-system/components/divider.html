Divider

A divider is a hairline that separates groups when space alone is not enough: a card footer, a menu group, the line above the site footer.

WCAG 2.2 AA<hr> / role="separator"Status: stable

Overview

Reach for spacing first: the 4px scale already separates most groups. Use a divider when two adjacent groups would otherwise read as one, such as a card's footer actions, a menu's destructive group, or a long settings form split into topics. Do not add a rule under every list item inside a bordered card; one edge is enough.

  • Horizontal: <hr> or .divider between blocks; 24px above and below.
  • Vertical: separates inline groups in a toolbar or footer row.
  • With label: names the split ("or", "Earlier"), for example between sign-in methods or notification dates.

Anatomy

  1. Rule1px --border-width-hairline in --color-border-default; decorative.
  2. Label (optional)Overline type in --color-fg-subtle, centred with --space-3 either side.

Sizes

One weight: the hairline. Use space, not a thicker rule, for stronger separation.

States

Dividers are static and have no interactive states. They change only with the theme and with prefers-contrast: more, where --color-border-default becomes the strong border.

Responsive behaviour

  • Horizontal dividers span their container at every width.
  • Vertical dividers only appear in rows that stay on one line; when a row wraps on phones (footer, toolbars), drop the vertical divider and rely on the wrap gap.

Theming

Dividers read --color-border-default (grey 200 light, grey 750 dark) and --border-width-hairline. The label reads --color-fg-subtle. The high-contrast preference strengthens the rule automatically.

Accessibility

Role and pattern

<hr> has the implicit separator role and is announced as a thematic break; use it between topics. Purely decorative lines (card footers, the topbar edge) are CSS borders, not elements. A vertical separator uses role="separator" aria-orientation="vertical". A labelled divider is plain text with decorative lines, so the label is read.

Keyboard

KeyAction
NoneDividers are not focusable and not interactive.

Focus

Not applicable; dividers never take focus.

Labelling

Label text is real content ("or", "Earlier"). Do not add aria-label to decorative rules.

Contrast

The rule is decorative and exempt from 1.4.11; grouping is also conveyed by spacing and headings. The label text meets text contrast:

Divider label on page

Motion

None.

Touch

Not a target. Keep at least 8px between a divider and any neighbouring target.

Content

  • Labels are one or two words in sentence case ("or", "Earlier", "This week"); styled as overline.
  • A label that needs a sentence is a heading, not a divider.

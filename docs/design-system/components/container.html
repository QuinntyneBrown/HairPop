Container, grid and stack

Layout primitives place everything else: the container sets page margins and the maximum width, stacks and clusters space siblings, and grids divide the width into the tokens' columns and gutters.

WCAG 2.2 AALayoutStatus: stable

Overview

Never position components with ad-hoc margins. Compose a page from these primitives so spacing and columns come from the layout tokens and change in one place at each breakpoint.

  • Container (.container) centres content, caps it at --layout-container-max (1280px) and applies --layout-margin on both sides. .container--narrow caps at --layout-form-max (608px) for forms and auth.
  • Stack (.stack) is a vertical flow with one gap: 8, 16 or 32px.
  • Cluster (.cluster) is a wrapping row with a 12px gap: buttons, chips, metadata.
  • Grid (.grid) uses --layout-columns (4, 8, 12) and --layout-gutter; .grid--auto fills with cards at least --layout-card-min (288px) wide.
  • Feature grid (.feature-grid) is the 1 → 2 → 3 column card grid of the gallery and matching braiders; detail grid (.detail-grid) is the 2:1 main and aside of style detail and braider profile.
  • App shell (.product-shell + .product-main) keeps the footer at the bottom and spaces the page's top-level blocks 24px apart.

Anatomy

  1. MarginViewport edge to content: --layout-margin 16 → 32 → 48px.
  2. Column--layout-columns 4 → 8 → 12 equal tracks (minmax(0, 1fr)).
  3. GutterBetween columns: --layout-gutter 16 → 24 → 32px.

States

Layout primitives are static; their only changes are the responsive column, gutter and margin steps documented under Responsive.

Responsive behaviour

  • Media queries are min-width only, in rem, so they follow the reader's font size.
  • Content reflows to 320px CSS width with no horizontal scroll (WCAG 1.4.10).
  • .product-main has 24px top padding on phones and 32px from 768px, with 48px at the bottom.

Theming

Layout primitives use no colour. They read --layout-* and --space-* tokens only, which themes do not change. A denser product could override --layout-gutter and --layout-margin at :root; every grid follows.

Accessibility

Role and pattern

Primitives are <div>s with no role; landmarks come from the shell: <header class="topbar">, <main id="main" class="container product-main">, <footer class="site-footer">, and <aside> for the detail grid's second column.

Keyboard

KeyAction
TabFollows DOM order, which must match visual order. Never reorder with order or grid placement in a way that breaks reading order.

Focus

Not focusable. scroll-padding-top on html keeps focused elements clear of the sticky topbar (WCAG 2.4.11).

Labelling

A <section> or <aside> used as a region gets aria-labelledby pointing at its heading.

Contrast

Not applicable: primitives draw nothing.

Motion

None.

Touch

Cluster and stack gaps keep adjacent targets at least 8px apart.

Content

  • Keep prose within --layout-measure (65ch); paragraphs cap themselves.
  • Order content by importance in the DOM: the detail grid's main column comes first, the aside second.

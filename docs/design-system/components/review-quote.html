Review quote

A review quote shows one published review: its score and date, the customer's words, who wrote it for which service, and a way to report it.

WCAG 2.2 AAfigure + blockquoteStatus: stable

Overview

Use a review quote for each published review on a braider profile, and once, without its action, inside the Report a review dialog so the person can see what they are reporting. Reviews render as text: customer words never become markup (L2-039).

Anatomy

  1. HeaderScore (rating summary, score only) and a <time>.
  2. Quote<blockquote> in body text; long words wrap.
  3. Author<figcaption>: name · service.
  4. ActionLink-style button "Report review", named with the author for screen readers.

Sizes

One size; it fills its card column.

States

The review itself is static. The report action follows the link button states (hover, focus, active). A review the viewer reported stays visible and unchanged; moderation happens elsewhere.

Responsive behaviour

  • The header wraps the date under the score below about 16rem.
  • Quotes wrap anywhere, so pasted URLs never cause horizontal scroll.

Theming

The divider uses --color-border-default; text roles follow the body, caption and body-small tokens in both themes.

Accessibility

Role and pattern

<figure> with <blockquote> and <figcaption>: the quote is associated with its author.

Content

  • Dates as "3 Oct 2026".
  • The author is the reviewer's name as published; the service is the booked service name.
  • Never truncate a review; reviews are limited to 1000 characters.

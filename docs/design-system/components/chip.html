Chip

Chips are compact pill controls for narrowing a list: pick a style type, show an applied filter, remove it again.

WCAG 2.2 AANative <button> + aria-pressedStatus: stable

Overview

Use chips for quick, reversible choices that filter what is on screen: style type on the gallery, applied filters above braider results. Use a button for an action, a badge for read-only status, and a radio group or select inside forms.

  • Filter chips toggle with aria-pressed. In a single-choice set ("All styles", "Braids", "Twists", "Locs") exactly one is pressed at a time and pressing it again does nothing.
  • Input chips show an applied filter ("Under $200", "Within 10 km") and carry a remove button.
  • Static chips are tags on content ("Knotless", "Toronto West") with no interaction.

Anatomy

  1. LabelLabel font (14px semibold); a noun or short phrase.
  2. Remove button (input chips)24px circular target with the close icon and its own aria-label.
  3. Pill32px (or 40px) tall, --radius-full, 1px strong border, 12px padding.

Sizes

Small (32px) is the default in filter rows. Medium (40px) lines chips up with a 40px search field or button on the same row.

Default --control-height-sm (32px) · .chip--md --control-height-md (40px).
HTML
<button type="button" class="chip" aria-pressed="true">Braids · 32px</button>
<button type="button" class="chip chip--md" aria-pressed="true">Braids · 40px</button>

  • Selected is aria-pressed="true": plum-50 fill, plum border and plum label, the same selected look as the current nav link.
  • Disabled is rare: keep a filter enabled and show "No matches" rather than greying out choices people might want.
  • Loading: after a chip is pressed, the results area, not the chip, shows the busy state.

Responsive behaviour

  • Chip rows wrap (.chip-row, flex-wrap: wrap, 8px gap); they never scroll sideways and never shrink a label.
  • At 360px the style-type row ("All styles", "Braids", "Twists", "Locs") fits on one line; a longer set wraps to two.
  • The small chip is 32px tall; with 8px between neighbours it meets the 24px target rule. Prefer .chip--md when a row is the main control on a phone screen.

Theming

Component tokens --chip-bg, --chip-fg, --chip-border and --chip-height map to surface, default text, strong border and the small control height; the selected state swaps them to --color-accent-subtle, --color-fg-accent and --color-accent. Dark mode uses plum-950 with a plum-300 label.

/* Chips on a sunken well */
.well .chip { --chip-bg: var(--color-bg-surface-raised); }

Accessibility

Role and pattern

Filter chips are <button type="button" aria-pressed> toggle buttons (APG Button, toggle) inside role="group" with an aria-label naming the set. Input chips are a text label plus a real remove <button>. Static chips are spans.

Keyboard

KeyAction
Tab / Shift+TabMoves between chips (each is a tab stop) and remove buttons.
Space / EnterToggles a filter chip; activates a remove button.
Backspace / DeleteOn a focused remove button, also removes the filter.

Focus

The shared ring on :focus-visible. After a filter is removed, focus moves to the next chip, or to "Clear filters" when none are left; never to the top of the page.

Labelling

The chip text is the name and aria-pressed carries the state ("Braids, toggle button, pressed"). Remove buttons name what they remove: "Remove filter: under $200". Announce the new result count in a polite live region after each change ("12 braiders").

Motion

Background and border transition over --duration-fast; zero under reduced motion.

Touch

32px chips with 8px gaps pass the 24px minimum; the remove button is a 24px circle. Use 40px chips where the row is a phone screen's primary control.

Content

  • Sentence-case nouns: "Braids", "Twists", "All styles". One or two words.
  • Input chips state the value, not the field: "Under $200", "Within 10 km".
  • Put "All …" first in a single-choice set, pressed by default.
  • Pair applied-filter chips with "Clear filters" when there are two or more.

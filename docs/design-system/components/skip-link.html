Skip link

The skip link is the first thing a keyboard user reaches on every HairPop page. It jumps past the top bar straight to the content.

WCAG 2.2 AANative <a href="#main">Status: stable

Overview

Every page starts with <a class="skip-link" href="#main">Skip to content</a> as the first element in <body>. It stays off-screen until it receives keyboard focus, then slides into the top-left corner above the top bar. Activating it moves focus to <main id="main">, skipping the brand, four nav links, Updates and the account link (seven tab stops on every page).

  • One skip link per page, always to the main content. Add a second ("Skip to results") only for very long filter areas.
  • It is not a replacement for landmarks and headings; pages still need them.

Anatomy

  1. Label"Skip to content", --text-label, --color-fg-default.
  2. ContainerRaised surface, --radius-md, --shadow-3, padding --space-2 by --space-4, layer --z-tooltip, plus the focus ring.

Variants

One variant. .skip-link--demo exists only so documentation can show it in flow; never use it in product pages.

Sizes

The skip link has one size.

States

In product pages the default state is off-screen (top: -6rem); :focus-visible brings it to --space-4 from the top. The demo modifier keeps it in flow so every state is visible.

Responsive behaviour

  • The same at every width: it appears at --space-4 from the top-left corner, over the sticky top bar.
  • It never wraps; at 320px "Skip to content" fits with room to spare.
  • On touch-only devices it is never seen; it is still the first element for switch and screen-reader users.

Theming

It reads --color-bg-surface-raised, --color-fg-default, --shadow-3 and the focus-ring tokens. In the dark theme it is grey 800 with grey 150 text and a plum 300 ring, standing out from the grey 900 top bar beneath it.

Accessibility

Role and pattern

A native same-page link (WCAG 2.4.1 Bypass Blocks). The target is <main id="main">; browsers move focus there when it is followed. For client-side routing, set tabindex="-1" on main and focus it in script.

Keyboard

KeyAction
Tab (first press)Focuses and reveals the skip link.
EnterMoves focus to the main content; the next Tab lands on the first control in it.
Tab (again)Hides it and moves on to the brand in the top bar.

Focus

The shared 2px ring plus the raised shadow make it obvious over the top bar. It sits at --z-tooltip so nothing covers it.

Labelling

The link text is the name: "Skip to content". Never "Skip navigation" or an icon.

Contrast

Label on raised surface
Focus ring on raised surface
Focus ring on top bar

Motion

It slides down over --duration-fast; under reduced motion it appears instantly.

Touch

When visible it is at least 40px tall and wide enough for its label, well above the 24px minimum.

Content

  • Always "Skip to content", in sentence case.
  • A second skip link names its target: "Skip to results".

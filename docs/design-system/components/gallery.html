Gallery

A gallery shows a braider's portfolio as a grid of square photos with captions, so customers can see real work before they request; in the braider app each photo has a remove action.

Overview

Use a gallery for portfolio work: on the public braider profile ("Recent work") and on the braider's profile content screen, where each item can be removed. It is not a carousel and never auto-plays. When there are no photos, render an empty state instead of an empty grid (L2-007).

Anatomy

  1. Gridul.gallery, auto-fill columns of at least 10rem, --space-3 gap.
  2. PhotoSquare, object-fit: cover, --radius-md; descriptive alt.
  3. CaptionStyle · month, caption text.
  4. ActionsBraider app only: a small ghost "Remove" button named with the caption.

Variants

Read-only on the profile; editable in the braider app.

Sizes

Items size to the grid; there is one item size.

States

  • Loaded: the photo fills its square.
  • Missing photo: the accent art panel with the sparkle icon keeps the grid even.
  • Empty: replaced by an empty state with "Add photo" in the braider app.
  • Remove: button hover, focus and busy follow the button states.

Responsive behaviour

  • Two columns at 360px, three or four in a profile card on desktop; the minimum column is 10rem (or the full width when narrower).
  • Captions wrap; nothing scrolls horizontally.

Theming

The art panel uses --color-accent-subtle and --color-fg-accent, the same pairing as story-card art, so both themes read alike.

Accessibility

Role and pattern

A list of figures: screen readers announce "list, 3 items" and each photo's alt text with its caption.

Keyboard

KeyAction
TabRead-only: skipped. Editable: moves through the Remove buttons in order.

Focus

The shared ring on Remove; after removal, focus moves to the next item's Remove button, or to "Add photo" when the list is empty.

Labelling

Alt text describes the work ("Medium knotless braids shown from the back"); the art placeholder is decorative. Remove buttons include the caption.

Contrast

Caption
Art icon

Motion

None.

Touch

Remove buttons are small buttons with a 44px target.

Content

  • Caption: style · month and year ("Medium knotless braids · Oct 2026"), at most 120 characters.
  • Alt text says what the hair looks like, not "photo of".

Textarea

A textarea collects a few sentences in the person's own words: a review of their visit with Nia, hair details for a request, a reason for a report.

WCAG 2.2 AANative <textarea>Status: stable

Overview

Use a textarea when the answer is more than one line: "Your review", "Hair details", "Anything Nia should know?". For a single value use a text field. The textarea always sits inside a form field.

  • Default starts at 100px (2.5× the control height) and can be resized vertically.
  • Auto-grow grows with the text up to about ten lines, then scrolls; use it for reviews.
  • With counter shows "used / limit" when a limit exists and turns red beyond it.

Anatomy

  1. LabelVisible, from the form field.
  2. Text areaBody font, 8 × 12px padding, --radius-md, at least 100px tall.
  3. HelpOne sentence; linked by aria-describedby.
  4. Counter (optional)Caption, tabular numbers, right aligned.

Both themes

Responsive behaviour

  • Full width of the form column at every breakpoint; never paired in a two-column row.
  • On phones prefer auto-grow over a manual resize handle, which is hard to drag on touch screens.
  • Text stays 16px so iOS does not zoom on focus.

Theming

Shares the text field's component tokens (--field-bg, --field-fg, --field-border, --field-border-hover). The counter reads --color-fg-subtle and switches to --color-danger-fg with data-over="true".

Accessibility

Role and pattern

Native <textarea> with <label for>; help, error and counter joined in aria-describedby.

Keyboard

KeyAction
Tab / Shift+TabMoves into and out of the textarea (Tab never inserts a tab character).
EnterInserts a new line; it does not submit.

Focus

Same as the text field: accent border plus a flush 2px ring.

Labelling

The label asks the question. The counter is announced politely only when the person pauses near the limit (a debounced live region), not on every key.

Contrast

Edge on card
Counter
Over-limit counter and error

Motion

Border and ring transition over --duration-fast; auto-grow is immediate.

Touch

At least two rows tall (well over 44px); tapping the label also focuses it.

Content

  • Label as a question or noun phrase: "Your review", "Anything Nia should know?".
  • Help text suggests what a useful answer covers, not rules.
  • State limits in characters: "Shorten this to 200 characters or fewer."

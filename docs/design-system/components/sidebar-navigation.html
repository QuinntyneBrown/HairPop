Sidebar navigation

Sidebar navigation lists many destinations in labelled groups beside the page. HairPop's customer screens do not need it yet; it is reserved for account areas and the future braider studio.

Overview

Use sidebar navigation when an area has more than six destinations or needs grouping, such as a future account area (Appointments, Updates, Saved braiders, Account settings, Privacy choices) or a braider studio. For the customer journey's four destinations, use the top bar; for switching views of one list, use tabs.

  • Grouped lists links under small uppercase group labels.
  • Collapsible groups use <details> so long sections can fold away; the group holding the current page stays open.
  • With counts adds a badge to a link (unread updates, pending requests).

Anatomy

  1. Group label.sidebar__group: overline, --color-fg-subtle, not a link.
  2. Current link.nav-link with aria-current="page"; accent-subtle background, accent label.
  3. Count (optional)A count badge pushed to the end of the link.
  4. Container256px (--layout-sidebar-width), surface, right hairline, --space-4 padding, 4px between links.

Variants

Group by the customer's task, not by system object. Put icons on every link or on none.

Sizes

Sidebar navigation has one width (--layout-sidebar-width, 256px) and one link height (44px).

States

Links share the top bar's nav-link states, forced here with data-state.

  • Group expanded or collapsed: native <details open>; the browser exposes the state, no ARIA needed.
  • Drawer open (below 1024px): data-open="true" shows the sidebar; the button that opens it has aria-expanded="true".
  • Links are never disabled; remove a destination the customer cannot reach.

Responsive behaviour

  • From 1024px (--layout-breakpoint-lg): the sidebar is a sticky, full-height column in .sidebar-layout and scrolls on its own when its links overflow.
  • Below 1024px: it is hidden and opens as a drawer from a menu button in the top bar (data-open="true"), full width below 640px.
  • Group labels and counts stay visible at every width; labels never truncate (keep them to three words).

Theming

The sidebar reads --color-bg-surface, --color-border-default and the nav-link tokens; group labels read --color-fg-subtle. In the dark theme the column becomes grey 900 against the grey 950 canvas and the current link plum 300 on plum 950. Re-theme by overriding semantic tokens on a wrapper, not the rules.

Accessibility

Role and pattern

<nav aria-label="Account"> landmark containing plain links. Collapsible groups use native <details>/<summary> (APG Disclosure). The drawer below 1024px follows the dialog rules when it covers content.

Keyboard

KeyAction
Tab / Shift+TabMoves through group summaries and links in order.
EnterFollows a link.
Enter, SpaceOn a group summary: expands or collapses it.
EscIn the drawer: closes it and returns focus to the menu button.

Focus

The shared ring on each link and summary. Opening the drawer moves focus to its first link; closing returns focus to the menu button.

Labelling

The nav has its own label, different from the top bar's "Primary". The current page uses aria-current="page". A count badge needs hidden text that says what it counts ("Updates 2, 2 unread").

Motion

Link colours change over --duration-fast; the drawer slides in over --duration-slow. Both are instant under reduced motion.

Touch

Links are 44px tall with 4px between them; summaries are at least 24px tall.

Content

  • Links name destinations as nouns in sentence case: "Appointments", "Account settings", "Care and review".
  • Group labels are short and describe ownership or purpose: "Your HairPop", "Account", "Legal".
  • Use the same name for a destination here, in the top bar and in the page's <h1>.

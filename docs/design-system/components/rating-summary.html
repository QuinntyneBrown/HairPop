Rating summary

A rating summary shows a braider's published-review score and how many reviews it comes from, so Maya can judge Nia at a glance without trusting a number that hides how little evidence it has.

WCAG 2.2 AAPublished reviews onlyStatus: stable

Overview

Use a rating summary wherever a braider's reputation is shown: matching results, the profile head and the reviews section. It reads only from published reviews (L2-008). When a braider has none, it says Not yet rated rather than showing 0 or a placeholder score. It is read-only; collecting a rating uses a horizontal radio group.

Anatomy

  1. StarFilled 16px star, --rating-star; decorative.
  2. ValueOne decimal, label weight, tabular figures.
  3. Count"· 86 reviews", muted body-small.
  4. Spoken textVisually hidden: "Rated 4.9 out of 5 from 86 reviews"; the visual part is aria-hidden.

Sizes

One size; it inherits body-small and sits beside card titles and profile names.

States

Static and never focusable. The two data states are rated and unrated; a braider whose only reviews are pending moderation is unrated.

Responsive behaviour

  • Wraps between value and count only when its container is narrower than about 9rem; the star always stays with the value.
  • Large counts use thousands separators: "· 1,284 reviews".

Theming

--rating-star aliases --color-warning-icon (amber-500 light, amber-300 dark). Value text uses --color-fg-default, the count --color-fg-muted.

Accessibility

Role and pattern

Plain text; no role. The visual part is hidden from assistive technology and one sentence is read instead, so "star 4.9 dot 86 reviews" is never announced.

Keyboard

KeyAction
TabSkips it; not focusable.

Focus

None.

Labelling

The hidden sentence carries the score and count. The star is decorative, so its colour needs no non-text contrast; the value carries the meaning.

Content

  • One decimal for averages ("4.9"), none for a single review ("5").
  • "1 review", "86 reviews"; never "86 ratings".
  • Unrated copy is "Not yet rated", never "0.0" or "New".

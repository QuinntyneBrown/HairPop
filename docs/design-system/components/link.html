Link

Links take people somewhere: to a style, a braider's profile, the terms. They are always underlined, so they never rely on colour alone.

Overview

Use a link when activating it navigates: to another page, a section, a route-backed dialog, or an external site. Use a button when activating it changes something. A button-styled link (<a class="btn">) is still a link and follows these rules for its markup.

  • Inline links sit inside running text: "Read Nia’s cancellation policy before you send a request."
  • Standalone links end a card or section and carry an arrow: "Explore Knotless braids". One per card.
  • External links leave HairPop. They show the external icon and say "opens in a new tab" when they do.
  • Inherit links take the colour of their container in alerts, toasts and the footer, and stay underlined. Breadcrumb links are not link components: the breadcrumb draws muted plain anchors that underline on hover.

Anatomy

  1. TextSays where the link goes; it is the accessible name.
  2. Underline1px at rest, 2px on hover, 0.15em offset. Never removed.
  3. Trailing icon (optional)Arrow for standalone links, external icon for other sites; aria-hidden.

Inherit colour

.link--inherit takes the container's text colour and stays underlined, so it keeps the container's contrast pair and still reads as a link. Containers tune it with two knobs rather than reaching into the link: --link-inherit-font-weight (alerts and the error summary set it to semibold) and --link-inherit-hover-fg (the footer sets it to --color-fg-default). With neither set, the link keeps the container's weight and colour on hover too, and only the underline thickens.

Sizes

Links take the size of the text they sit in; standalone links use the label font at 16px.

States

Hover thickens the underline and darkens the colour; focus shows the shared ring; active keeps the hover colour. Visited links are not restyled: HairPop's links mostly lead back to the same browsing pages, so a visited colour would add noise rather than orientation. Links have no disabled state; remove the link instead.

Responsive behaviour

  • Inline links wrap with their sentence; never set white-space: nowrap on long link text.
  • Standalone links are at least 24px tall (--target-min) so they meet the target size on phones; give them their own line in cards. When the label wraps (narrow cards, 200% text) the arrow keeps its 1rem size at the end of the row (.link__arrow is flex: none).
  • The external icon sits on the text line after the last word and wraps with it (display: inline-block, vertical-align: -0.125em).
  • Footer links keep 24px targets and wrap onto a second line below 640px.

Theming

Links read --color-fg-link and --color-fg-link-hover. In light they are plum 700 and 800; in dark plum 300 and 200, all above 7:1 on every surface. Inside alerts, toasts and the footer the link inherits (.link--inherit, color: inherit) so it never introduces a new contrast pair; containers set --link-inherit-font-weight and --link-inherit-hover-fg to re-skin it.

Accessibility

Role and pattern

Native <a href>; see the APG Link pattern. Never an anchor without href, never a <span> with a click handler.

Keyboard

KeyAction
Tab / Shift+TabMoves focus between links in DOM order.
EnterFollows the link. (Space scrolls the page; it does not follow links.)

Focus

The shared 2px ring with 2px offset on :focus-visible. Standalone links are inline-flex, so the ring wraps the text and arrow as one shape.

Labelling

Link text makes sense alone (SC 2.4.4): "Explore Knotless braids", not "Explore" or "Learn more". Repeated card links name their card. Decorative arrows are aria-hidden; external links add a visually hidden "(opens in a new tab)" when they use target="_blank".

Contrast

Link on card
Hovered link on card

The underline, not colour, distinguishes links from text (SC 1.4.1).

Motion

The standalone arrow shifts 4px right on hover over --duration-fast; reduced motion makes it instant.

Touch

Standalone and footer links are at least 24px tall. Inline links inside paragraphs fall under the SC 2.5.8 inline exception but are never placed closer than one word apart.

Content

  • Describe the destination: "Explore Knotless braids", "Read Nia’s reviews", "Terms of use".
  • Use sentence case and no trailing punctuation inside the link.
  • Do not start with "Click here" or "Link to"; screen readers already announce "link".
  • Keep the arrow for standalone links only; inline links never carry icons except the external icon.

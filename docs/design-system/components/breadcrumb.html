Breadcrumb

A breadcrumb shows where a detail page sits and gives one tap back to its parent: Styles › Knotless braids, Braiders › Nia Okafor, Appointments › HP-1048.

WCAG 2.2 AA<nav> + <ol>Status: core set, recommended for detail pages

Overview

Use a breadcrumb at the top of a detail page, above the page header, when the page has a clear parent the customer may want to return to: Knotless braids, Nia's profile, appointment HP-1048 and the braiders for a style. Without it the only way back is the browser button or the top bar.

  • Use it only for hierarchy (Styles › Knotless braids), not for the history of how someone arrived.
  • Skip it on top-level pages (Styles, Braiders, Appointments, Help) and on auth and error pages.
  • The last item is the current page, unlinked and marked with aria-current="page".

Anatomy

  1. Ancestor link--color-fg-muted, underline on hover, 24px tall target.
  2. Separator"/" drawn by CSS in --color-fg-subtle; hidden from assistive technology.
  3. Current pagePlain text, --color-fg-default, medium weight, aria-current="page".

Responsive behaviour

  • Below 768px: only the parent shows, with a leading chevron-left icon ("‹ Knotless braids"). It stays inside <nav aria-label="Breadcrumb">; the current page is already the <h1>. The full path is always rendered: the stylesheet hides the other items (display: none, so they leave the accessibility tree) and the parent's separator.
  • From 768px: the full path shows and the chevron is hidden. Long paths wrap onto a second line rather than truncating.
  • The chevron is rendered on the parent link only (the last ancestor), so it never sits in the middle of a path.
  • Place it inside .product-main directly above the page header, aligned to the content edge.

Theming

The breadcrumb reads --color-fg-muted (links), --color-fg-subtle (separator) and --color-fg-default (current and hover). In dark they become grey 350, 400 and 150 on the grey 950 canvas. It has no component tokens; theme it through the semantic tier.

Accessibility

Role and pattern

APG Breadcrumb: <nav aria-label="Breadcrumb"> containing an ordered list; the current page carries aria-current="page". Separators are CSS content with empty alternative text (content: "/" / ""), so they are not read.

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links; the current page is skipped.
EnterFollows the link.

Focus

The shared 2px ring with 2px offset around each link.

Labelling

The landmark is labelled "Breadcrumb" (one breadcrumb per page). Link text is the destination page's topic ("Nia Okafor", not "Nia’s profile page").

Contrast

Ancestor link on page
Separator on page
Current page
Focus ring

Motion

None; underline and colour change instantly.

Touch

Links are at least 24px tall (--target-min) with 8px between items. On phones the single parent link sits alone, well clear of the page header.

Content

  • Each item is the short name of its page in sentence case: "Styles", "Knotless braids", "Nia Okafor", "HP-1048".
  • Do not add "Home"; Styles is HairPop's home.
  • The last item matches the page's <h1> topic.

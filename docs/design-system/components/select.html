Select

A select picks one value from a list the person does not need to compare side by side: a travel distance, a sort order, one of Nia's offered times when there are many.

WCAG 2.2 AANative <select>Status: stable

Overview

Use a native <select> when the answer is one value from a known list of more than five options. With five or fewer options that people should compare, use a radio group. When people need to type to find an option among hundreds, a combobox (not yet in the system) is the right tool.

  • Native select is the default: it gets the platform picker on phones, works with every assistive technology and needs no script.
  • A custom listbox is only built when the native control cannot do the job, and then follows the APG Listbox pattern.

Anatomy

  1. LabelVisible, from the form field.
  2. Selected valueBody font; the field reserves 40px on the right for the chevron.
  3. ChevronTwo CSS gradients in currentColor, so it follows the text colour and the disabled state.

Native select; with a placeholder option that cannot be submitted; with option groups.

Both themes

Responsive behaviour

  • Full width of its column; on phones the operating system's picker opens, which is why the native select is preferred.
  • From 768px two short selects may share a .form-row (distance and sort).
  • The platform truncates long option text in the closed field; keep options under 30 characters.

Theming

Uses the field tokens (--field-bg, --field-border …) plus --select-chevron for the chevron size. color-scheme in each theme makes the native option list dark in the dark theme.

Accessibility

Role and pattern

Native <select> with <label for>. Changing the value never submits or navigates by itself (SC 3.2.2); results update after an explicit "Show braiders".

Keyboard

KeyAction
TabFocuses the select.
↑ / ↓Changes the value (Windows) or opens the list (macOS).
Space / Alt+↓Opens the list.
Type a letterJumps to the matching option.
EscCloses the list without changing the value.

Focus

Accent border plus a flush 2px ring, as for text fields.

Labelling

The visible label names the choice. A placeholder option ("Choose a distance") is disabled and has an empty value so it cannot be submitted.

Motion

The border transitions over --duration-fast; the list is the platform's.

Touch

40px tall and full width; the platform picker provides large targets.

Content

  • Options are short and parallel: "Within 5 km", "Within 10 km", "Within 25 km".
  • Order options logically (ascending distance, chronological times), not alphabetically.
  • Placeholder options start with "Choose".

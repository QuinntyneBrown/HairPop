Component · Data display

Stat

Fact tiles answer the questions people ask before they book: how long, how much, how long it lasts. One number, one label, side by side.

WCAG 2.2 AATabular numbersStatus: stable

Overview

Use a fact tile for a short, comparable figure that helps a decision: "4–7 hours · Typical time", "$160–$300 · Typical price", "From $180 · Knotless braids". Group two to four in a .fact-grid. Use a stat (large value, label, optional delta) for summaries with a trend, such as a braider's requests this month. Use a description list when the labels matter more than the values or there are more than four facts.

  • Fact tile: value first (h4 role), label beneath (muted, small), on a subtle background.
  • Stat: label first, then a large value in the h2 role, then an optional delta with arrow, sign, colour and words.

Anatomy

  1. Valueh4 role (16px semibold), tabular figures; an en dash for ranges.
  2. LabelBody small, muted; what the number measures.
  3. Tile--color-bg-subtle, --radius-md, 12px padding; tiles share a grid with 16px gaps.

Sizes

One size each: the fact tile uses the h4 role, the stat the h2 role. Use the stat when a value needs more presence.

States

Facts are read-only and not focusable, so they have no hover, focus, active or disabled state. They change with the data:

  • Loading: the tile keeps its size with a title and a text skeleton; the grid's container sets aria-busy="true".
  • Not listed: say who can answer ("Ask Nia") rather than a dash or "N/A".
  • Long value: the value wraps inside its tile; tiles in the same row stretch to equal height.

Responsive behaviour

  • The grid is repeat(auto-fit, minmax(8rem, 1fr)): two tiles per row at 360px inside a card, three or four on wider cards. No breakpoints needed.
  • Values never truncate; they wrap. Keep them under about 12 characters so they stay on one line at 360px.
  • A stat's value keeps the h2 role, 36px at every width.

Theming

The tile reads --color-bg-subtle for its fill, --color-fg-default for the value and --color-fg-muted for the label; deltas read --color-success-fg and --color-danger-fg. In dark mode the tile becomes grey-800 on a grey-900 card, so it still reads as inset.

/* Facts on a sunken well use the surface instead */
.well .fact { background: var(--color-bg-surface); }

Accessibility

Role and pattern

Plain elements; no ARIA pattern. Reading order is value then label ("4–7 hours, Typical time"), which makes sense spoken. Do not use <strong> for the value; the weight is visual, not importance.

Keyboard

KeyAction
TabSkips facts and stats; they are not interactive.

Focus

None.

Labelling

Ranges use an en dash, which most screen readers read as "to". Arrows in deltas are aria-hidden; the words carry direction ("+6 from September", "1 h slower").

Motion

Values do not count up or animate. Skeletons pause under reduced motion.

Touch

Not a target.

Content

  • Value: number plus unit, short: "4–7 hours", "$160–$300", "From $180". En dash for ranges, no spaces around it.
  • Label: what it measures, sentence case: "Typical time", "Typical price", "Typical wear".
  • Say "typical" or "from" for estimates; the braider confirms the final price.
  • Whole-dollar prices have no decimals: "$180", not "$180.00".

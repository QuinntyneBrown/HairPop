Component · Data display

List

A list stacks short, similar items in one column: notifications, a braider's services, a help topic's articles. Each row is one line or two, with an optional avatar or icon.

Overview

Use a list for a run of homogeneous items that people scan top to bottom and open one at a time. Use cards when each item carries media or several actions, a table when people compare fields across items, and a plain <ul> or <ol> in prose (the "Prepare for your visit" steps).

  • Simple: one line per row.
  • Two-line: a title and a meta line in --color-fg-muted.
  • With avatar or icon: a leading 40px avatar or 20px icon.
  • Interactive: each row is a link (<a class="list__item list__item--interactive">), 44px tall at minimum.
  • Unread: an accent dot before the title plus the word "Unread" for screen readers.

Anatomy

  1. Leading avatar or icon (optional)Decorative when the title already names the person.
  2. Title.list__title: label type at 16px.
  3. Meta (optional).list__meta: body-sm in --color-fg-muted; time first.
  4. Trailing chevron or badge (optional)Chevron for navigation rows; a badge for status.

Sizes

One row density; rows grow with a second line. Use a dense table for compact data.

States

Only interactive rows have states. Hover tints the row; focus draws the shared ring inside the row; the current item uses aria-current="true" and the accent tint; unread rows add a dot and a hidden "Unread:" prefix.

Responsive behaviour

  • Lists are one column at every width; on wide screens cap them with the detail grid's main column or --layout-form-max rather than stretching rows to 1280px.
  • Titles wrap; meta lines may use .truncate on phones when the full text is available on the next screen.
  • Trailing badges stay on the title row and never push the title below 50% of the row.

Theming

Rows read --color-border-default (dividers), --color-bg-subtle (hover), --color-accent-subtle (current) and --color-accent (unread dot). Place the list in a .card.card--flush for the surface and edge.

Accessibility

Role and pattern

A native <ul> (or <ol> when order matters) so the item count is announced. Interactive rows are <a> inside <li>; never role="listbox" unless the list is a selection widget.

Keyboard

KeyAction
Tab / Shift+TabMoves between row links.
EnterOpens the focused row.

Focus

The shared ring on the row link. Each row is one tab stop; do not nest a second link inside an interactive row.

Labelling

Give a list a name when several sit on a page (aria-label="Notifications"). Unread state is in text ("Unread:" visually hidden, or a visible badge), not only the dot. Leading avatars repeat the title's name and are aria-hidden.

Contrast

Title on row
Meta on row
Title on hovered row
Title on current row
Unread dot on row

Motion

Hover tint transitions over --duration-fast; reduced motion makes it instant.

Touch

Interactive rows are at least --target-comfortable (44px) tall and span the full width.

Content

  • Titles say what happened or what the item is ("Nia received your request").
  • Meta starts with time ("Today at 9:42 am", "Yesterday"), then one clause of detail.
  • Sentence case, no trailing full stop on titles.
